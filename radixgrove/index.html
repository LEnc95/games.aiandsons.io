SMALL DIGITS. GROWING POSSIBILITIES.

Radix Grove

Pack a decimal seed count into a different number base. Each abacus column holds a digit from 0 to base − 1. Multiply each digit by its column weight; make the four contributions add up to the target. Restore five groves before three incorrect checks.

Tap a column or its button to increase its digit. Digits wrap back to zero.
← / → select · ↑ / ↓ change · 0–5 set digit · Enter check / continue
U undo · P or Escape pause · R restart · F fullscreen · Escape exits fullscreen.
Correct checks unlock the next grove. No time limit. Undo keeps the edit count.
