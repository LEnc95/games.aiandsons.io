THE HARBORMASTER'S LEDGER

Harbor Match

Find a berth for every boat. Each row needs one anchor on an open circle, and each berth can host only one boat. Fit the whole fleet across five harbor manifests.

Tap an open circle, or select a boat button and then a lettered berth.
↑/↓ select boat · ←/→ select berth · Space assigns · 1–5 assign A–E · 0 unassigns
Enter starts/continues · V inspects · U undo · C clear · P pause · R restart
F fullscreen · Escape exits. Three failed inspections end the shift. No time limit.
An anchor marks an assignment; a red ring marks a berth booked twice. × means incompatible.
