THE TREETOP TELEPHONE COMPANY

Cable Canopy

Link every cabin to the treetop network. Each cable uses the number of spools printed on its tag. Connect all cabins within the spool budget across five woodland puzzles.

Tap a numbered cable tag or its button to install or remove it. A solid line is installed; a dashed line is available. Cabin letters identify endpoints; line crossings are not junctions.
All cabins must connect, directly or indirectly, using no more than the budget. Three failed network tests end the shift. Undo and clear are free; there is no time limit.
1–9 toggle cables · Arrows select tag · Space toggles · Enter starts or continues
V test · U undo · C clear · P pause · R restart · F fullscreen · Escape exits.
