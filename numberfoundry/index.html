THE POCKET WORKSHOP · ARITHMETIC PUZZLES

Number Foundry

Four ingots. One exact number. Combine pairs with arithmetic to cast the target, using every ingot across five workshop orders.

Select the FIRST ingot, then the SECOND: subtraction and division follow that order.
Choose +, −, × or ÷, then Combine. Division must be exact; intermediate values must be whole numbers from 0 to 999. Invalid combinations cost nothing.
Reach one ingot equal to the target, then Forge. Three wrong forges end the shift. Undo and reset are free; there is no time limit.
1–4 selects ingots · Arrows move cursor · Space selects · + / − / * / / choose operation
Enter combines or continues · V forges · U undo · C resets order · P pause · R restart · F fullscreen · Escape exits.
